# Bloom

Prenatal medication companion PWA: logs doses and meals, sends push + email reminders to the patient and caregiver, and emails a daily summary. Next.js + Supabase + Resend, Asia/Manila time.

See `CLAUDE.md` (rules, run/test/deploy) and `docs/PLAN.md` (architecture, schema, screens, phases).

Bloom is a reminder and logging tool, not medical advice. Regimen changes come only from the OB.
